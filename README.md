# لوكسوريا - منصة العقارات

منصة عقارات عربية متخصصة للهواتف المحمولة مع نظام إدارة كامل.

## 🚀 المميزات

- **واجهة عربية بالكامل** - تصميم RTL متكامل
- **موبايل فقط** - مصمم خصيصاً للهواتف المحمولة
- **نظام إدارة** - مستويين (مدير ومدرج)
- **البحث والفرز** - خيارات بحث متقدمة
- **ألوان عصرية** - تصميم جذاب للشباب

## 👥 مستخدمين النظام

### المدير (admin/admin123)
- إدارة كاملة للنظام
- إضافة وحذف المستخدمين
- عرض الإحصائيات
- تعديل كل البيانات

### المدرج
- عرض الشركات والعقارات
- إضافة شركات وعقارات جديدة
- لا يمكنه تعديل البيانات الموجودة
- لا يمكنه إدارة المستخدمين

### المستخدم العام
- عرض الشركات والعقارات فقط
- البحث والفرز
- لا يحتاج تسجيل دخول

## 🔧 التثبيت

1. **إنشاء مشروع Firebase**
   - اذهب إلى https://console.firebase.google.com
   - أنشئ مشروع جديد
   - قم بتفعيل Firestore Database
   - قم بتفعيل Storage

2. **تكوين Firebase**
   - افتح `js/firebase-config.js`
   - استبدل القيم ببيانات مشروع Firebase الخاص بك:
   ```javascript
   const firebaseConfig = {
       apiKey: "YOUR_API_KEY",
       authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
       projectId: "YOUR_PROJECT_ID",
       storageBucket: "YOUR_PROJECT_ID.appspot.com",
       messagingSenderId: "YOUR_MESSAGING_SENDER_ID",
       appId: "YOUR_APP_ID"
   };
   ```

3. **تشغيل الموقع**
   - افتح `index.html` في المتصفح
   - أو استخدم خادم محلي:
   ```
   python -m http.server 8000
   ```
   ثم افتح http://localhost:8000

## 🗄️ قواعد أمان Firestore

أضف هذه القواعد في Firestore Console:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```
